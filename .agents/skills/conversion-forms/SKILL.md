# Skill: Conversion and Forms

Use this skill when creating page sections, CTA strategy, forms, conversion flows, and thank-you experiences.

## Canonical source of truth

Use `.agents/business-facts.md` for:

* phone numbers
* email
* service area references
* trust points
* approved service details

Never use contact or trust information that conflicts with the business facts file.

## Primary conversion goals

Optimize for:

* quote requests
* phone calls
* contact form submissions
* fix request submissions

## Primary CTA

Preferred primary CTA:

* Get a Free Quote

Good secondary CTAs:

* Call Now
* Text Us
* Request Service
* View Gallery

## Header and hero guidance

Header should make it easy to:

* call
* text
* request a quote

Hero should answer:

* what the company does
* who it serves
* where it serves
* why it is trustworthy
* what to do next

## Approved trust points near CTA

Use approved facts from `.agents/business-facts.md` near conversion points, including:

* in business since 2015
* over 900 homes serviced annually
* fully insured
* lights provided
* storage included

## Form guidance

Keep forms short and useful.

Recommended quote form fields:

* name
* phone
* email
* service address
* project type
* message

Recommended fix request fields:

* name
* phone
* email
* service address
* issue description

Only add fields if they materially improve lead quality.

## Contact page guidance

The contact page should:

* make the primary CTA obvious
* show call and text options clearly
* reduce distractions
* reassure the user that the company serves their area
* support both residential and commercial inquiries

## Fix request page guidance

The fix request page is primarily for existing customers.

It should feel:

* fast
* supportive
* low-friction
* clear

Use reassuring language and simple next steps.

## Thank-you page guidance

The thank-you page should:

* confirm the submission was received
* explain what happens next
* provide the main phone number
* provide the text number if useful
* avoid unnecessary clutter

## Accuracy rules

Do not:

* imply a physical office visit
* use unapproved phone numbers
* invent response-time guarantees unless confirmed
* create unsupported offers

## Output expectations

Every conversion-focused page should:

* present a clear next step
* show trust before or near major asks
* work well on mobile
* use approved business facts consistently
